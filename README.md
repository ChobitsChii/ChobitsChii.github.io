## Enthaltene Open-Source-Projekte
- [**Games Monorepo**](https://github.com/ChobitsChii/games) – Kleine, modern gestaltete Spiele mit Godot 4.7 (GDScript) für Linux, Windows und Web ([Web-Portal](https://chobitschii.github.io/games/)).
- [**Diorama Sandbox**](https://github.com/ChobitsChii/diorama-godot) – Gemütliches Low-Poly 3D Diorama Island Bauspiel in Godot 4 für Linux, Windows und Android.
- [**ModulNest**](https://github.com/ChobitsChii/ModulNest) – Modulare, selbst hostbare PHP-Webplattform mit Single-Sign-On und Rollenverwaltung.
- [**ModulNest-Modules**](https://github.com/ChobitsChii/ModulNest-Modules) – Offizielle Module und signierter Modulkatalog für ModulNest.
