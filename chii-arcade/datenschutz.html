2. Aufruf der Website

Informationen zur Verarbeitung durch GitHub und möglichen Übermittlungen in Drittländer enthält die Datenschutzerklärung von GitHub. Auf deren interne Speicher- und Löschfristen habe ich keinen unmittelbaren Einfluss.

3. Nutzung der Android-App

Die App benötigt kein Konto. Sie ruft über HTTPS den öffentlichen Spielekatalog, Bilder und Veröffentlichungsinformationen von GitHub Pages sowie APK-Dateien von GitHub Releases ab. Dabei können GitHub dieselben technischen Verbindungsdaten übermittelt werden.

Die App speichert lokal den zuletzt erfolgreich geladenen Katalog, Bilder für den Offline-Modus und die Offline-Einstellung. Sie prüft bei freigegebenen Spielpaketen lokal, welche Version auf dem Gerät installiert ist. Die Android-Systeminstallation wird erst nach einer ausdrücklichen Nutzeraktion geöffnet. Eigene Werbung, Analyse-SDKs oder ein selbst betriebener Trackingdienst sind nicht integriert.
